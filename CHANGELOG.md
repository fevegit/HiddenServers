# Changelog

## v1.0.0

- First stable public release.
- Added server hiding from the guild context menu.
- Added complete folder hiding from the guild context menu.
- Added strictly separate persistence for hidden servers and hidden folders.
- Added separate recovery lists in the plugin settings.
- Added a Vencord Toolbox action to restore all hidden items.
- Fixed a selector bug that could hide the entire server navigation.
- Added a safety guard that refuses unsafe guild navigation rules.
